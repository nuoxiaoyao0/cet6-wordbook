# 六级词汇 · 书页模式 v1.1

一本**不遮中文**的电子单词书。单词在上、音标和词性紧跟、中文释义紧接着在下，例句再下一行
—— 全页从不遮挡，也不需要「翻卡」。每页由脚本按真实行高**精确排满一屏**，翻页就像翻纸质单词书。

- 纯静态站点：无后端、无账号、数据全在本机
- 可安装成 PWA：iPhone「添加到主屏幕」后全屏运行，断网也能看
- 词量 **3991 词**，含音标 / 词性 / 中文释义 / 例句 / 同近义词 / 同根词 / COCA 词频

线上地址：`https://nuoxiaoyao0.github.io/cet6-wordbook/`

## v1.1 新增

| 功能 | 说明 |
| --- | --- |
| **学习计划** | 选「几天背完」（15/30/45/60/90 或自己填）+「每天几次」（1/2/3），自动算出每天与每次的词量、预计完成日期；顶部实时显示「第 3/30 天 · 今日 12/134」，点「背今天的词」直接进当日任务 |
| **复习模式** | 标记后自动排复习：间隔 1 → 2 → 4 → 7 → 15 → 30 天；「复习」视图只出今天到期的词，标 ✓ 就往后推，标 ✕ 就从 1 天重来 |
| **高频词标记** | 按 COCA 词频星标：★★ 核心（≤2000，500 词）、★ 高频（≤4000，826 词）；「高频」视图一键只看重点 |
| **顺序版 / 乱序版** | 目录与设置里都能切；乱序用固定种子，切来切去不会丢进度，顺序版始终保留 |
| **细节动效** | 翻页左右滑入、标记弹一下、抽屉毛玻璃遮罩 + 弹性上滑；系统开启「减弱动态效果」时自动关闭 |
| **抽屉背景修复** | 详情/目录面板改为不透明纸色 + 背景模糊，不再出现书页文字透上来叠在一起 |

## 词量对不对？（实测审计）

用第三方六级词表（qwerty-learner `CET6_T`，2345 词）交叉验证：

```
本书词量                          3991
第三方六级词表                    2345
本书缺失（三方表有、本书没有）    0 词    ← 覆盖 100%
本书多出（派生词/超纲词）         1646 词
原文含中文释义                    3991 / 3991 = 100%
有音标/有例句                     3955 / 3898（97.7%）
收录于 2–3 份词表（核心）         1424 词
COCA 词频 ≤2000                   500 词
COCA 词频 2001–4000               826 词
```

结论：**没有少**，比单一百词表更全；多出来的是另两份词书里的派生词与超纲词，
可用「高频」视图只看重点，或用「跳过已掌握」过滤。

## 数据来源

词条来自 GitHub 开源项目 [kajweb/dict](https://github.com/kajweb/dict) 的 `CET6_1/2/3`
三本词书（音标、词性中文释义、例句、同近义词、同根词），去重合并后按字母序排列；
词频取自 [skywind3000/ECDICT](https://github.com/skywind3000/ECDICT) 的 COCA `frq` 字段。
仅供个人学习使用，请遵守原项目许可。

## 用法

| 动作 | 效果 |
| --- | --- |
| 左右滑动 / `←` `→` / 底部按钮 | 翻页 |
| 轻点单词或音标 | 朗读（系统语音，可切美音/英音） |
| 轻点释义或例句 | 详情：全部例句、同近义词、同根词、词频、复习进度 |
| 长按词条（0.5 秒） | 同上 |
| 点词条右侧圆点 | 标记循环 `○ 未看 → ✓ 已掌握 → △ 待再看 → ✕ 不熟`，并自动排复习 |
| 左上 ☰ / 点标题 | 目录：学习计划卡、视图切换、顺序/乱序、A–Z 跳转、List 进度 |
| 右上 🔍 | 搜单词或中文释义 |
| 右上 ⚙️ | 字号、主题（纸书/清爽/夜间）、例句、音标、高频星标、每页词数、导出 CSV、打印 |

一屏能放多少词（脚本实测，始终「一页一屏」不出现滚动条）：

| 屏幕 | 开例句 | 关例句 |
| --- | --- | --- |
| iPhone SE (375×667) | 5 | 8 |
| iPhone 14/15 (390×844) | 7 | 11 |
| Pro Max (430×932) | 8 | 13 |
| iPad (834×1112) | 11 | 17 |

想更密：⚙️ 字号调到 13–14；想更疏：调到 20。

## 装到 iPhone

1. Safari 打开 `https://nuoxiaoyao0.github.io/cet6-wordbook/`
2. 底部「分享」→ **添加到主屏幕**
3. 之后从主屏图标打开：全屏、无地址栏、断网可用

## 更新版本

改完代码后推送，并把 `sw.js` 里的 `CACHE = 'cet6-book-v1.1.0'` 改成新版本号
（否则手机端会继续用旧缓存）。已经装到主屏的，打开两次即可看到新版。

```bash
cd cet6-wordbook
git add -A && git commit -m "更新" && git push
```
